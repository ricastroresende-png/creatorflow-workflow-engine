# Auditoria Plantão360 — pendente de arquivos corretos

A auditoria estratégica completa do Plantão360 **não foi executada neste repositório**, porque o aplicativo, seus protótipos, assets de marca, landing pages, materiais de aquisição e evidências visuais **não estão presentes aqui**.

Este repositório contém apenas a skill `creatorflow-workflow-engine`, portanto qualquer diagnóstico profundo sobre Produto, UX/UI, paywall, aquisição, monetização, retenção ou break-even do Plantão360 exigiria evidências externas que não estão versionadas neste workspace.

## Arquivos necessários para executar a auditoria

Para realizar a auditoria corretamente, disponibilize o ZIP/pasta contendo, no mínimo:

| Categoria | Arquivos/evidências necessários |
|---|---|
| Direção e documentação | `README.md`, `CLAUDE.md`, documentação de produto, decisões, estado atual |
| Produto e interface | `Plantao360.html`, `src/app.jsx`, `src/screens.jsx`, `src/ui.jsx`, `src/data.jsx`, `src/desktop.jsx`, `src/desktop-v2.jsx`, `src/v2-app.jsx`, `src/v2-home.jsx`, `src/v2-kit.jsx`, `src/v2-newshift.jsx`, `src/v2-onboard.jsx`, `src/tokens.css`, componentes relacionados |
| Marca/design system | `Brand System - Plantao360.html`, versão standalone, logos, tokens, imagens, ícones e assets |
| Aquisição e comunicação | calendário editorial, stories, destaques, carrosséis, Reels, posts, legendas, hashtags, provas sociais e CTAs |
| Conversão | landing page de baixar app, versões standalone, links de loja e screenshots de store listing |
| Evidência visual | screenshots reais, mockups, uploads, exports, vídeos e gravações de tela |
| Dados de negócio | downloads, ativação, paywall views, conversão, assinantes, MRR, churn, custos, cohorts, Android vs iOS |

## Próximo passo correto

Quando os arquivos do Plantão360 forem adicionados ao workspace, a auditoria deve ser refeita a partir da leitura integral desses artefatos, separando explicitamente:

1. o que está confirmado pelos arquivos;
2. o que é inferência provável;
3. o que é hipótese a validar;
4. o que ainda é informação ausente.

Até lá, este repositório não deve conter uma auditoria conclusiva do Plantão360, para evitar recomendações baseadas em premissas incompletas ou em um contexto errado.
