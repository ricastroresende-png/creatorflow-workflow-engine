# 7-Day Pinterest Workflow – PDF-Ready Template

Use this outline to generate a clean, printable PDF that walks through a complete 7-day Pinterest marketing workflow. The template includes recommended formatting, daily checklists, AI prompts for pin design, and KPI tracking guidance.

## Visual Style Guide (for PDF)
- **Fonts:** Headings – Montserrat or Helvetica Neue; Body – Inter or Helvetica.
- **Colors:** Pinterest red `#BD081C` for accents, charcoal `#333` for text, light gray `#f8f9fa` page background, and subtle borders `#dee2e6`.
- **Layout:** Single-column, 800px max width, generous spacing, icons for section headers, dashed rules between list items, and checkboxes for action lists.
- **Page Footer:** Date generated and copyright line.

## Section 1 – Overview
- Brief description of Pinterest as a visual discovery platform.
- Objectives list (traffic, impressions, clicks, authority).

## Section 2 – 7-Day Structure
### Days 1–2: Foundation & Optimization
- Optimize profile (bio with keywords, site link, professional photo).
- Create 5–10 themed boards with keyword-rich titles and descriptions.
- Perform keyword research using search suggestions and guided search chips.

### Days 3–4: Pin Creation
- Ideal format: 1000x1500px, high contrast, legible text, strong CTA.
- Mix of pin types: Informative (40%), Inspirational (30%), Product (20%), Blog (10%).
- Design tips: vibrant colors, 2:3 ratio, clear focal point.

### Days 5–6: Distribution & Engagement
- Best times: 8–10 AM, 2–4 PM, 8–10 PM.
- Save to main + related + collaborative boards.
- Community interactions: comments, follows, replies.

### Day 7: Analysis & Optimization
- Metrics: Impressions, Pin Clicks, Saves, CTR.
- Optimization levers: replicate winners, adjust titles/descriptions, test formats, refine keywords.

## Section 3 – AI Prompts for Viral Pins
Include 10 prompt blocks covering tutorial, list, before/after, checklist, infographic, quote, product, statistic, step-by-step, and transformation pins. Use placeholders `[THEME]`, `[COLOR1]`, `[COLOR2]`, `[COLOR3]`, `[STYLE]` so designers can customize quickly.

## Section 4 – Keyword Strategy
- How to find keywords: search bar autosuggest, viral pin titles, guided chips.
- Where to place keywords: pin title, description, board name/description, ALT text, file name.

## Section 5 – High-Conversion Pin Design
- Elements: catchy 60-character title, high-res image, large legible text (≥32pt), strategic colors by intent, CTA examples.
- Mistakes to avoid: tiny text, clutter, low-quality images, poor contrast, missing subtle branding.

## Section 6 – Metrics & Optimization
- KPIs: Impressions (goal: +20% WoW), Engagement rate >2% (saves + clicks), CTR >0.5%, Save rate >1%.
- If impressions low → improve SEO/timing/frequency.
- If clicks low → redesign pins, stronger titles/CTAs.
- If saves low → add utility (tutorials/lists) and improve value.

## Section 7 – Weekly Content Calendar (15 pins)
- Monday: 3 informative pins (tutorials/guides)
- Tuesday: 2 inspirational pins (transformations)
- Wednesday: 3 list pins (compilations)
- Thursday: 2 product/service pins (conversion)
- Friday: 3 blog/article pins (traffic)
- Saturday: 2 quote pins (engagement)
- Sunday: Analytics review + next-week plan

## Section 8 – Launch Checklist
- Image 1000x1500px
- Title includes keyword
- Description optimized (100–200 characters)
- Link points correctly
- ALT text completed
- Appropriate board selected
- Visual quality check complete
- CTA included in design

## Section 9 – Profile Optimization Checklist
- Keyword-rich bio and memorable username
- Functional external link
- Professional profile photo
- Boards organized by theme with consistent covers

## Section 10 – Advanced Tips
- Activate Rich Pins for synced metadata.
- Use Pinterest Analytics for audience and performance insights.
- Join collaborative boards to expand reach.
- Publish Idea Pins for engagement priority.
- Maintain daily posting cadence and ongoing testing.

- Week 3: Scale pin production
- Week 4: Diversify pin formats
